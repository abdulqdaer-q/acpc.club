# Uncodixify Reference

Use this reference when a website starts drifting toward generic AI UI patterns.

## Core Rule

If a visual choice feels like the default AI move, reject it and choose the cleaner, harder, more ordinary option.

## Keep It Normal

- Use simple headers with real hierarchy.
- Use normal navigation with plain links.
- Use standard sections with predictable spacing.
- Use buttons with solid fills or borders and small radii.
- Use cards with subtle borders and shallow shadows.
- Use layouts with clear columns, ordinary grids, and functional containers.
- Use calm colors that come from the project itself.
- Use typography that reads like a real product, not a template.

## Hard No

- oversized rounded corners
- pill overload
- floating glass shells
- decorative blue-black gradients
- fake premium dark SaaS composition
- eyebrow labels and ornamental metadata
- fake charts or metric-card grids used as filler
- dramatic glows, haze, and blur-heavy panels
- decorative copy blocks that explain the obvious
- transform-heavy hover effects
- dead space created only to feel expensive

## Specific Anti-Patterns

Watch for these recurring mistakes:

- the same rounded rectangle repeated on every surface
- large detached sidebars with brand blocks
- heavy box shadows such as `0 24px 60px`
- uppercase labels with letter spacing used everywhere
- glossy gradient bars, donuts, and fake data visuals
- multiple panel variants solving no real problem
- footers or rails filled with ornamental meta information

## Color Guidance

1. Reuse the project palette first.
2. If the project has no palette, choose a restrained palette and keep it consistent.
3. Do not invent random color mixes.

For Aleppo CPC specifically:

- prefer muted dark neutrals for the base
- keep logo colors as accents, not wallpaper
- avoid pushing the full interface toward bright blue

## Practical Translation

When redesigning a page:

- strip decorative labels first
- reduce radii and shadows
- flatten overdesigned surfaces
- simplify CTA styling
- normalize navigation and footer behavior
- remove visual effects that do not add information
- keep storytelling in structure and media, not decorative chrome
